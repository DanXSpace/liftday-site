# liftday-site

The website for LiftDay at https://useliftday.com, published with GitHub Pages.

- `index.html`: home page
- `privacy/index.html`: privacy policy (https://useliftday.com/privacy). Its source text is `.scratch/r1-beta/launch/privacy-policy.md` in the app repo; keep them in step.
- `style.css`: the LiftDay brand colors (carbon, chalk, electric lime). Dark only, like the app.
- `brand/`: the horizontal wordmark and Lift Mark, copied unchanged from `branding/LiftDay-Brand-Assets/` in the app repo, plus favicon and Apple touch icon sizes of the default app icon.
- `fonts/`: Archivo Condensed ExtraBold for headings (SIL Open Font License, `fonts/Archivo-OFL.txt`).

Follow `docs/brand-guidelines.md` in the app repo: never retype "LiftDay" in a font to stand in for the wordmark, and don't recolor or redraw the mark.
